Download the primary dataset for this project from Kaggle. The most widely used and comprehensive version is the **Zomato Bangalore Restaurants** dataset 
It contains over 50,000 restaurant records, which matches the data cleaning logic and SQL queries provided in the project template.

**Download Link:**
[Zomato Bangalore Restaurants on Kaggle](https://www.kaggle.com/datasets/himanshupoddar/zomato-bangalore-restaurants)

**To download it:**
1. Create a free account on Kaggle if you do not already have one.
2. Click the **"Download"** button (usually a download icon or a button saying "Download (X MB)") in the top right corner of the dataset page.
3. Unzip the downloaded file to find the `zomato.csv` file.
4. Place this file inside your project's `data/` folder as `zomato.csv` to run the scripts.
